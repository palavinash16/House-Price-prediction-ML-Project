POST /predict Endpoint Example

Send JSON property features payload to receive instant valuation and confidence intervals.

curl -X 'POST' \
  'http://localhost:8000/predict' \
  -H 'Content-Type: application/json' \
  -d '{
    "Area_SqFt": 2250,
    "Bedrooms": 3,
    "Bathrooms": 2,
    "Stories": 2,
    "House_Age_Years": 8,
    "Garage_Cars": 2,
    "Neighborhood": "Suburbs",
    "Furnishing": "Semi-Furnished",
    "Has_Pool": "No"
  }'
